# Потенциал постов ВКонтакте как источника данных о количестве рабочих домов и их представленности в регионах Российской Федерации

## Структура репозитория

| Путь | Назначение |
| --- | --- |
| `src/etl/__init__.py` | Пакет подготовки публикаций ВКонтакте |
| `src/etl/extract.py` | Чтение CSV с диска или по прямой HTTP(S)-ссылке |
| `src/etl/transform.py` | Приведение типов и расчёт 21 текстового признака |
| `src/etl/validate.py` | Проверка данных перед записью |
| `src/etl/load.py` | Транзакционная запись выборки в SQLite |

| `scripts/` | Исходные скрипты сбора публикаций и подготовки данных для EDA |
| `notebooks/EDA.ipynb` | Разведывательный анализ данных |
| `docs/` | Описание исследования, источника и схемы датасета |
| `pyproject.toml` и `requirements.txt` | Настройки пакета и установка зависимостей |

## Запуск ETL

Требуется Python 3.11 или новее. Из корня репозитория выполните:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m etl.main --database db.sqlite3
```

Обязательный аргумент `--database` задаёт путь к файлу SQLite. SQLite входит в стандартную библиотеку Python. По умолчанию ETL скачивает [CSV проекта](docs/methods.md) с Google Drive. Другой источник можно указать аргументом `--source` или переменной `DATASET_URL` в окружении либо в файле `.env`. Аргумент командной строки имеет приоритет.

```bash
python -m etl.main --database db.sqlite3 --source data/VK_dataset.csv --limit 50
```

ETL принимает CSV в UTF-8 с разделителем-запятой и полями `id`, `search_query`, `city`, `region`, `source_type`, `date`, `author_link`, `link` и `text`. Он поддерживает сырой CSV из VK API и опубликованный датасет проекта. Текстовые признаки рассчитываются из текста публикаций при каждом запуске.

Пакет проверяет весь датасет, включая уникальность идентификаторов, даты в формате `ГГГГ-ММ-ДД`, ссылки на публикации и наличие текста. Если все проверки пройдены, ETL записывает в таблицу `vk_posts` первые строки в порядке исходного CSV. Значение `--limit` можно задать от 1 до 100, значение по умолчанию — 100. При каждом успешном запуске содержимое таблицы заменяется новой выборкой. Проверить результат можно из Python:

```bash
python -c "import sqlite3; print(sqlite3.connect('db.sqlite3').execute('SELECT COUNT(*) FROM vk_posts').fetchone()[0])"
```

## Сбор данных и EDA

Для исходных скриптов и ноутбука установите дополнительные зависимости из блока `dev`:

```bash
python -m pip install -e ".[dev]"
```

Порядок работы: `queries_generator.py` → `read_api.py` → `text_features_extraction.py` → `data_loader.py` → ноутбук. Для этих скриптов используются переменные `CORE_PATH` (путь к корню проекта), `VK_SERVICE_TOKEN` (сервисный токен VK API) и `DATASET_URL` (ссылка на CSV).

Разведывательный анализ данных представлен в Jupyter Notebook:

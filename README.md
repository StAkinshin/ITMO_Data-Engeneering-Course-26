# Потенциал постов ВКонтакте как источника данных о количестве рабочих домов и их представленности в регионах Российской Федерации

## Структура репозитория

Основные файлы и директории проекта:

- `scripts/queries_generator.py` — скрипт генерации поисковых запросов;
- `scripts/read_api.py` — скрипт получения публикаций через VK API;
- `scripts/text_features_extraction.py` — скрипт извлечения дополнительных признаков из текста публикаций;
- `scripts/data_loader.py` — скрипт загрузки и предварительной обработки датасета;
- `notebooks/EDA.ipynb` — Jupyter Notebook с разведывательным анализом данных;

Порядок запуска: queries_generator.py → read_api.py → text_features_extraction.py → data_loader.py → ноутбук

Для работы скриптов требуется файл .env с переменными: 
- `CORE_PATH` — путь репозитория на Вашем устройстве;
- `VK_SERVICE_TOKEN` — сервисный токен VK API, получается через VK Developers;
- `DATASET_URL` — ссылка на датасет, указана далее;


## Разведывательный анализ данных (EDA)

Разведывательный анализ данных представлен в Jupyter Notebook:

[`notebooks/EDA.ipynb`](notebooks/EDA.ipynb).

В нём рассматриваются основные характеристики собранного датасета, распределение публикаций, их географическая представленность и особенности текстовых признаков.

# ITMO_Data-Engeneering-Course-26
# Потенциал постов ВКонтакте как источника данных о количестве рабочих домов и их представленности в регионах Российской Федерации

## 1. Введение

**Рабочий дом** (работный дом, дом трудолюбия; далее — рабдом) — организация или форма занятости, при которой труд наёмного работника полностью или частично оплачивается не денежной компенсацией, а предоставлением места для проживания (койки в общежитии) и питания.

На данный момент официальная статистика, описывающая количество и территориальное распространение рабдомов на территории Российской Федерации, отсутствует. Во многом это связано с тем, что подобные организации имеют различный правовой статус, а часть из них осуществляет деятельность в «серой» зоне.

Отсутствие систематического мониторинга рабдомов представляет собой проблему, поскольку создаёт условия для применения неправомерных практик со стороны отдельных организаций: удержания документов, задержки или невыплаты заработной платы и других нарушений трудовых прав.

Особенно уязвимой аудиторией подобных организаций являются люди, оказавшиеся в трудной жизненной ситуации, в том числе люди, столкнувшиеся с бездомностью. Для них рабдомы могут выступать одним из немногих доступных вариантов получения временного жилья и питания. Однако при столкновении с неправомерными практиками условия жизни таких людей могут существенно ухудшаться по сравнению с их положением до трудоустройства.

Одним из возможных способов решения обозначенной проблемы является сбор и анализ объявлений рабдомов. Такие объявления встречаются преимущественно:
- в бумажном виде на улицах, особенно вблизи вокзалов, станций и остановок общественного транспорта;
- в интернет-пространстве — на специализированных сайтах, в публикациях социальных сетей и на платформах объявлений и услуг (например, Авито).

В рамках **Хакатона по социальным данным 2026**, организованного на базе ПАНДАН Европейского университета при поддержке проекта «Если быть точным», НКО «Ночлежка», оказывающая помощь людям, столкнувшимся с бездомностью, предложила данную проблему в качестве исследовательского кейса.

В составе команды была предпринята попытка оценить количество и территориальное распространение рабдомов на основе данных нескольких интернет-платформ. По итогам хакатона были получены первичные оценки, представленные в репозитории проекта:

[HomelessCase_SocialDataHack-26](https://github.com/StAkinshin/HomelessCase_SocialDataHack-26).

В ходе дальнейшего развития проекта было принято решение сосредоточиться на данных, полученных в результате парсинга поисковой выдачи браузеров, поскольку этот источник обеспечивал наибольший объём информации и наиболее широкую представленность регионов.

При этом данные социальных сетей, в частности ВКонтакте, также представляют интерес в качестве потенциального источника информации о рабдомах.

**Цель данного проекта — исследовать публикации ВКонтакте как потенциальный источник данных о количестве рабочих домов и их территориальной представленности в регионах Российской Федерации.**

## 2. Структура репозитория

Основные файлы и директории проекта:

- `cities.xlsx` — перечень городов Российской Федерации, используемый для формирования поисковых запросов;
- `queries_generator.py` — скрипт генерации поисковых запросов;
- `read_api.py` — скрипт получения публикаций через VK API;
- `text_features_extraction.py` — скрипт извлечения дополнительных признаков из текста публикаций;
- `data_loader.py` — скрипт загрузки и предварительной обработки датасета;
- `notebooks/EDA.ipynb` — Jupyter Notebook с разведывательным анализом данных;
- `VK_dataset.parquet` — итоговый датасет с публикациями ВКонтакте и извлечёнными текстовыми признаками.

## 3. Методика сбора данных

### 3.1. Формирование поисковых запросов

Для сбора публикаций ВКонтакте использовался поисковый запрос вида:

`"рабочий дом [город]"`

Выбор формулировки запроса основан на результатах Хакатона по социальным данным 2026.

В качестве географической основы использовался файл `cities.xlsx`, содержащий перечень из **181 города, расположенного в 85 регионах Российской Федерации**.

Для каждого города формировался отдельный поисковый запрос с помощью скрипта `queries_generator.py`.

### 3.2. Получение публикаций через VK API

Сформированные запросы отправлялись в ВКонтакте с использованием VK API.

Для каждой найденной публикации извлекались следующие поля:

| Поле | Описание |
|---|---|
| `id` | Идентификатор публикации |
| `search_query` | Поисковый запрос, по которому была найдена публикация |
| `source_type` | Тип источника |
| `date` | Дата публикации |
| `author_link` | Ссылка на автора публикации |
| `link` | Ссылка на публикацию |
| `text` | Текст публикации |

Дополнительно в датасет включались географические признаки:
- `city` — город, использованный при формировании поискового запроса;
- `region` — регион Российской Федерации, к которому относится соответствующий город.

Получение публикаций и формирование исходного датасета осуществлялись с помощью скрипта `read_api.py`.

### 3.3. Извлечение текстовых признаков

После сбора публикаций исходный датасет был дополнен признаками, рассчитанными на основе анализа текста публикаций.

Извлечение признаков осуществлялось с помощью скрипта `text_features_extraction.py`.

В результате были получены следующие дополнительные переменные:

| Признак | Описание |
|---|---|
| `text_char_count` | Количество символов в тексте |
| `text_word_count` | Количество слов в тексте |
| `text_sentence_count` | Количество предложений |
| `text_paragraph_count` | Количество абзацев |
| `text_avg_word_length` | Средняя длина слова |
| `text_avg_sentence_length` | Средняя длина предложения |
| `text_unique_words` | Количество уникальных слов |
| `text_unique_word_ratio` | Доля уникальных слов от общего количества слов |
| `text_url_count` | Количество URL в тексте |
| `text_hashtag_count` | Количество хештегов |
| `text_mention_count` | Количество упоминаний пользователей и сообществ |
| `text_emoji_count` | Количество эмодзи |
| `text_digit_count` | Количество цифровых символов |
| `text_punctuation_count` | Количество знаков пунктуации |
| `text_uppercase_ratio` | Доля символов в верхнем регистре |
| `text_has_question` | Наличие вопросительного знака |
| `text_has_exclamation` | Наличие восклицательного знака |
| `text_is_uppercase` | Признак того, что текст полностью написан заглавными буквами |
| `text_has_url` | Наличие URL в тексте |
| `text_has_hashtag` | Наличие хештегов |
| `text_has_emoji` | Наличие эмодзи |

Более подробное описание признаков и результаты их анализа представлены в разделе разведывательного анализа данных (EDA).
